# Учёт выдачи и возврата туристического снаряжения

## Возможности

- Добавление и просмотр клиентов.
- Добавление и просмотр снаряжения.
- Выдача снаряжения клиенту и оформление возврата.
- Просмотр истории выдач со статусами и датами.

## Запуск

Нужен JDK 21. Сборка выполняется через Gradle Wrapper.

## Структура

| Пакет | Назначение |
| --- | --- |
| `domain` | Клиенты, снаряжение, выдачи и статусы |
| `repository` и `repository.memory` | Интерфейсы хранилищ и хранение в памяти |
| `service` | Операции с клиентами, снаряжением и выдачами |
| `validation` | Проверка вводимых данных |
| `id` | Генерация идентификаторов |
| `ui` | Консольное меню и ввод данных |

## Правила

- Инвентарные номера уникальны с учётом регистра.
- Занятый предмет нельзя выдать повторно. Повторный возврат запрещён.
- Фактические даты выдачи и возврата не могут быть в будущем. Плановый возврат должен быть не раньше выдачи.
- Новая выдача предмета начинается в день его последнего фактического возврата или позже.
